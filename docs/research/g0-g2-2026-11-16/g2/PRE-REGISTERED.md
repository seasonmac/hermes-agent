# G2 preregistration — 2026-11-16
Synthetic fixed packets; no real trading, publishing, or repository edits. 3 tasks × 2 conditions × 2 repetitions = 12 intended task runs. Each task scored 0–5 (one point per declared rubric criterion). Scoring is descriptive, by the coordinating evaluator, not independent or statistically powered.
A: one model, self-review; no subagents. B: same main model plus exactly one same-model peer, explicit challenge and response through native collaboration tools. B is not automatically counted as peer collaboration: tool trace must show actual exchange.
Both conditions receive identical initial evidence and a correction file. They must record an initial view before reading the correction, then revise. This is staged evidence disclosure by instruction, not a timed injected user event. Each task: maximum 180s wall time, requested aggregate visible output <=900 words, final <=220 words, same reasoning effort medium, no external browsing or product edits. Native token hard caps are not established: actual usage must be reported, unequal usage cannot establish budget-matched superiority. Initial capability probe excluded from scored runs.
Save exact prompts, JSON events, outputs, wall time, errors. Mark timeout, missing peer trace, unavailable usage as invalid/incomplete; never substitute evaluator reasoning for the participants. Same task repeated creates correlated observations. This pilot can reveal setup/quality issues, not establish month-scale reliability.
