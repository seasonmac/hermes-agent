# 长资料成本转折与无预警召回结果

2026-11-16。完成8个真实模型样本、14次已记录模型用量增量，合计 **186,885 tokens**，低于预设240,000的整轮软门槛；没有失败重跑。32KiB与96KiB之间已出现全文和按需读取的总tokens排序反转，因此没有执行预先准备的192KiB候选档。静默过期和未预告断链各两组均通过预设事实及来源检查。

## 长资料成本

所有条件均由宿主直接把问题送入新Worker线程，无Router和READY回合。这是固定直达路径下读取/重建的边际成本，不是完整协作组启动成本。全文档位按紧凑JSON的UTF-8字节计量；32KiB为32,768字节，96KiB为98,304字节。C1两档入口相同，为1,768字节。

|---|---:|---:|---:|---:|---:|---:|---:|---|
| [L32-C0](L32-C0/observation.json) | 1 | 16,522 | 0 | 167 | **16,689** | 16,689 | 19.73 | 0/0 |
| [L32-C1](L32-C1/observation.json) | 2 | 22,637 | 11,136 | 245 | **22,882** | 11,746 | 13.92 | 0/0 |
| [L96-C0](L96-C0/observation.json) | 1 | 27,134 | 0 | 167 | **27,301** | 27,301 | 15.92 | 0/0 |
| [L96-C1](L96-C1/observation.json) | 2 | 22,629 | 10,112 | 237 | **22,866** | 12,754 | 19.76 | 0/0 |

C0=全文内联，C1=小入口加按需读取。缓存是输入的子集，推理输出已计入输出，没有重复加总。墙钟含专用进程启动和收尾。

32KiB时，按需读取比全文总量高37.11%；96KiB时低16.24%。C1两档都只批量读取E-A1、E-A2、E-A4、D-A-v1、D-A-v2一次，返回923字符，随后续跑回答；两次总量分别22,882和22,866，路径基本相同。C0一轮直接回答，输入随资料量从16,522增加到27,134。

**观测到的总token成本转折区间为32–96KiB。** 这是两档之间的排序反转，不是经过细分或重复验证的精确临界值。没有继续二分，避免把单次波动包装成精确阈值。也没有把上一轮不同基础预算配置的样本混入本轮对照。

**金额转折点未确定。** 两个全文样本缓存输入为0，按需样本分别命中11,136和10,112，缓存冷热没有控制；即便32KiB下按需总tokens更高，其非缓存输入加输出反而更少。没有真实账单或统一的输入/缓存/输出价格，不能用任意一个token口径冒充实际费用。

- **静默过期全文组：**主动重读DATA-A和SUMMARY-A，返回417字符；答案采用2022年，来源为DATA-A。全文在这里也发生一次额外读取，总量25,868。

- **静默过期按需组：**一次读取E-A1、E-A2、E-A4和DATA-A，返回745字符；同样采用2022年并保留暂停，未把数据就绪消息当作人类授权。总量22,924。

两个unknown是符合预先标准的缺证处理，不计召回错误。四组其余授权、目标、数据、进展及来源均正确；逐字段检查和原始结果在各目录score.json、answer.json、reads.json。全文提供了冲突材料也没有免除核验成本，说明“需要几轮核验”与“文本多长”必须同时计量。

## 解释边界和设计输入

1. 长度增长来自一个低相关的合成市场历史档案，关键事实及对象关系不变；模型可凭明确任务归属跳过该档案。这测到的是“可跳过资料很多”时的收益，不是所有长文件的通用转折点。如果大部分长正文都必须读取，收益可能明显变小或消失。

2. 每条件一次。C1两档入口相同、调用路径相同且总量相近，支持当前区间观察，但不支持稳定节省率、统计显著性或默认按某个KB数切换。

3. 静默过期仍有可发现的源索引，完整数据记录与Worker摘要角色可区分；没有模拟摘要和存储同时错误、权威来源顺序不明、工具返回缓存旧值或中途更新。两组能纠正这个冲突，不等于系统已实现自动失效传播。

4. 未预告断链已经实际出现读取失败；没有测不可枚举的旧任务、错误ID指向另一真实记录、深层引用环或模型上下文压缩。上述短测不是一个月运行验收。

5. 当前适合采用“目标/授权/当前步骤及紧邻证据内联，低相关长档案外置”的方向。选择依据应包含预计读取轮数、必需资料比例和实际缓存，而不能只看全文长度。摘要应保留可核对来源，读取失败允许保留未知；这些是后续设计输入，本轮未写产品实现。
