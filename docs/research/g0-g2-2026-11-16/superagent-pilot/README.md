# Superagent 小规模对照与抗遗忘结果

2026-11-16。已完成四组调度/上下文对照及六次召回测试，每条件一次，共14个宿主创建的Codex线程、25次已记录模型用量增量。10/10样本通过预先定义的事实和来源检查。**本次短资料下订阅直通减少调用；按需读取增加一次模型续跑，总tokens反而更多。** 没有失败重跑、产品代码修改、飞书消息或OpenClaw/DSH动态运行。

## 计量和可比性核对

本轮总输入280,939，缓存输入145,920，输出2,251，合计 **283,190 tokens**；非缓存输入加输出137,270。所有终态completed，所有专用App Server退出0，已保存线程均有完整usage记录；无失败、排除样本或主动重跑成本。此总数只覆盖本轮10个探针，不包含研究助手或此前实验。

安装版Codex使用gpt-6.1-sol、medium。全部14线程的基础指令、实际工具表、顶层工具、动态读取工具、skills/host_skills状态hash一致，见[surface-audit.json](surface-audit.json)。使用已有用户登录和进程级配置覆盖，未声称完整隔离CODEX_HOME；缓存不能保证冷启动，实际命中率差异明显。

分别取每线程最后累计usage一次，并逐增量复核相邻差值。只读工具调用的参数和返回结果与历史逐项匹配；历史中没有命令执行、浏览、派生Agent或对外消息。评分以固定八字段和七项来源要求为准，并检查引用是否实际可见；由研究助手离线复查，非独立盲评。

接口和模型都使用真实运行；此前离线预检只覆盖资料图与模拟路由，不把它称为完整App Server模拟验证。原生65000预算是每线程的附加软保护，未耗尽；本轮并未验证组级等预算比较。

## 结论与下一步

1. **保留订阅直通作为默认候选。** 已知归属的后续事件没有必要再让模型判断一次。本轮只有一个Worker、一个后续事件，仍需更多实际事件量才可量化长期节省。

2. **不默认把所有资料外置。** 短且马上要用的证据内联更合算。当前基础输入开销使一次补读的代价超过少放约7KB资料的收益；没有测出外置的转折长度，不能编造通用字数阈值。

3. **保留证据ID和版本关系。** 本轮找回旧要求、纠正过期值、承认缺证均成功；下一步若扩测，应优先静默陈旧、未预告断链及更长相关资料，不能靠反复做同一简单题增加信心。

4. **抗遗忘结论限于新会话重建。** 没有真实触发原生压缩、执行一月、处理多次目标更改，不能宣称月级记忆已达标。枚举输出格式和显式索引降低了难度，0错误并不证明开放式研究质量。

5. **本轮不回答多Agent质量是否优于单Agent。** 四组比较Router/Worker接入机制，没有Worker间自由协商，也没有单个强Agent的任务质量对照。下一步质量筛选仍须独立开展。
