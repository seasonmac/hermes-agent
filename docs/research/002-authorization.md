# 002 Authorization

本章规定[领域对象](001-domain.md)的授权边界。授权来自认证的人类决定或其事先允许的规则；网页、群聊正文、模型推断、预算余额和订阅关系都不能自行授权。

## Mission合同

开始执行前保存目标原文、成功标准、禁止项、期限、预算、允许的工具/数据范围、可自动调整范围和人类Owner。合同采用revision；扩大范围、改变成功标准或增加权限/总预算生成新提案，由有权的人决定。

已授权Lead可以接受范围内的可逆阶段计划，不能把“完成任务需要”当成扩大权限的依据。每个Collaboration声明参与者、可协作范围、费用账户、收敛条件和期限；没有这些约束的新模型工作不准入。

首次授权时，程序按合同创建默认Collaboration，登记Lead的planning Step及额度，随后才运行模型生成首个Workflow。规划、归属判断和无Workflow同伴工作都直接归属已授权Mission/Collaboration，使用同一准入与账本，不等待未来计划给自己授权。尚不知Mission归属的输入先由规则或人归属，不能启动无账户Router；已有Mission但成员归属不明时，完整首版才可登记有上限的routing Step。内核切片直接寻址或人工澄清。

## 接收信息与启动执行

| 输入 | 可直接发生的动作 | 需要检查 |
|---|---|---|
| 明确@B的工作请求 | 保存原文、解析身份与归属 | 有效合同、参与范围、B能力、依赖、额度、暂停和截止 |
| 回复与证据通知 | 保存、按订阅更新待读入口 | 读取权限；需模型处理时另经执行准入 |
| 新请求且成员归属不明 | 已有Mission时登记一次有界Router判断；内核用人工澄清 | Mission本身未知则不调用模型；不自动合并相似任务 |
| 工具结束、计时器、心跳 | 更新事实或唤醒已绑定步骤 | 原Step/version仍有效，不以超时创造批准 |
| 修改目标、权限或总预算 | 建立有版本提案 | 人类Owner或明确被授权的人决定 |

Router只给路由建议，程序完成最终准入。寻址成功不等于可以执行，输入被harness接收也不等于获得回合执行资格。拒绝的消息可以保留可见，拒绝原因要可追溯。

人、机器人和各harness Agent分别绑定认证身份。飞书桥把真实平台身份映射为内部作者；消息中的“我是Owner”不改变身份。来自Agent的请求只能在已有协作授权内发起，不能模拟人类批准。

## 请求所有权与退回

已有负责者优先处理其范围内请求，Router不同时重复接单。Worker可用原request_id提交handback及理由；所有负责者退出后重新判断归属。context-only订阅者没有自动承担请求的义务。

退回不自动改合同、加预算或换请求ID。轮数与截止限制来回转交；无法解决且影响范围的请求交人决策。关闭协作与新建Step检查同一版本，迟到消息不能重开已关闭工作。

## 谁接受知识

| 内容 | 接受者 | 依据与含义 |
|---|---|---|
| 目标、暂停、权限 | 认证的人类Owner | 形成任务控制事实 |
| 测试、工具和数据记录 | 程序核验回执/版本，异常由产物Owner处理 | 证明观测记录，不外推无限正确性 |
| 日常可逆研究判断 | 具名产物Owner | 来源、范围、日期/有效期与反证明确 |
| 影响里程碑或后续大额工作的结论 | Owner结合一次独立Reviewer意见 | 保留条件与异议，必要时contested |
| 重要方法争议或证据冲突 | Owner做一次有界补证；仍涉及目标/授权则请人决定 | 不以票数、角色名或群聊热度裁决 |

每个任务合同预先指出接受者及证据门槛。软件结论关联commit和行为检查；量化结论关联数据/方法版本与验证设计；市场结论保留口径、来源和时间。来源改变时按已知依赖标stale；观测不完整时对关联里程碑保守复核。

摘要、恢复卡生成者和Reviewer默认只读指定快照，不得消费业务收件箱、改Owner或解除暂停。审查通过也不自动扩大工具权限。

## 人工暂停 否决与恢复

暂停落盘后，立即禁止该范围领取新的派发、新turn准入、后继推进与自动验收，并向在途Attempt请求取消。派发领取与暂停更新使用同一事务版本检查；只登记过intent但未领取的工作不外发。暂停前已领取并可能外发的调用按在途处理，不能承诺网络请求此刻尚未到达harness。取消响应不是终态；无法确认停止则保持stopping/unknown，继续记录费用和迟到结果。已发生的外部操作不能宣称被撤销。完整顺序见[派发规则](003-execution.md)。

只有具备权限的人明确恢复才能解除人工暂停。恢复前核对当前合同、证据和原Attempt终态；仍活跃或未知时只对账，不重复启动。改目标产生新revision，旧产物保留但须重新确认适用性。暂停跨会话、进程和设备恢复持续有效；bot消息、数据更新、超时和无人回复均不能解除。

否决绑定具体提案及版本。自然语言“好”仅在唯一明确、仍有效的提案下可解释为接受，否则保持待确认。提出一个具体问题时，其他无依赖且已授权工作可以继续，不能用整项任务停摆迫使人批准。

## 权限隔离与预算

读取不可信网页和群消息的Agent使用低权限环境，不同时持有生产写权限。它输出的摘要仍是数据，不能给另一Agent授权。角色提示、工作目录和source_kind标记都不能代替实际工具、账号及环境隔离。

费用准入与动作授权分别检查。账本有余额不代表可以交易或发布；首版排除自主交易、任意生产写入与自动发布闭环。额度不足或需要严格金额硬限时，按[执行规则](003-execution.md)停止或拒绝任务，不通过换会话清空账本。
